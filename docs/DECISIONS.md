# Decision Register

Milestones update this register when they settle a decision. Every in-scope requirement is traced in the requirement-to-test matrix created in M1, with high-risk entries marked separately. Settled contract decisions update their requirement rows and test/oracle coverage before implementation. Fixture IDs refer to [Named Contract Fixtures](testing/strategy.md#named-contract-fixtures).

| Dirty contributing layers on file-backed refresh | M3 | **Chosen:** fail with a source-access conflict. Rejected: evaluating in-process state with a divergence diagnostic. May upgrade to a private disk view if one is found that is cheap enough (M1: feasible but slow). Revisited under "Strictness of the file-backed refresh contract". | `F-DIRTY-LAYER` |
| Private disk view feasibility | M1 | **Settled:** feasible in correctness but too slow as built. Anonymous copies of every reachable layer, with remapped asset paths, matched disk on the probe scene. On ALab it gave the same prim paths and type names as a normal open (values not compared), but took 16–17 s against 0.5–0.7 s for a normal open (warm cache). Relocating the scene (copy or symlink) leaks through absolute-path references. Untested: resolver search paths, asset-path expressions, clips, `.usdz`, and lazy copying. Keep the conflict failure unless M3 finds a cheaper view. See the [feasibility record](feasibility/runtime-record.md#private-disk-view). | M1 feasibility record |
