# `proscenium.interface`

The temporary UI, which M12 replaces (M7 plan, settled 3): the Source Select tool and minimal panels. Tier 10, above `ui/`'s widget displays and below `proscenium.addon`: it imports only `proscenium.api` and `proscenium_ui`'s widgets, besides `bpy` and USD, so replacing it touches neither the product nor the widgets (`tests/bpy_free/test_import_tiers.py` checks it). It reaches the product, the bindings, their synchronization, and interaction with their displays, only through `api/`; a widget only reads a stage its host gives it. Its operators declare `UNDO` only where the API pushes no undo step of its own, as for a selection; an operator calling an API function that pushes one, such as a synchronization, declares none.

Code in other units reaches it through the modules `__init__.py` exports ([import rules](../README.md#import-rules)); tests reach into any module.

| File | Holds |
|---|---|
| `__init__.py` | The package's exports: its modules. |
| `source_select_tool.py` | The Source Select tool, ported from the bridge's `select_tool.py`: a click picks what its own ray hits as the display draws it, each object's bounds box or an empty marker near its origin, shift toggles and ctrl removes, a drag selects a box by elements' world bounds' centers, and the sidebar's Proscenium tab sets the level and lists the scene's targets. Managed content is selectable exactly while a window showing it has the tool active, which message-bus subscriptions to the workspaces' tools and the windows' workspaces follow. |
| `binding_panel.py` | The binding panel in the sidebar's Proscenium tab: the scene's bindings, listed with one call per draw (`Bindings.binding_statuses`), each with its name, attachment, and state or why it can't be used, and a synchronize button, whose operator declares no `UNDO`, since the API pushes the step. |
| `source_inspector.py` | The source inspector in the sidebar's Proscenium tab: `proscenium_ui`'s scene graph widget over the live stage of the binding its dropdown chooses, the inspector holding no stage, and whether the prim selected in the tree is displayed. With its sync toggle on, the tree's selected prim and the scene's source selection mirror each other, a row selecting its prim's floor as an undo step, and the source selection selecting its active entry's row. Below the tree, the property viewer widget shows the selected prim's properties at the time code the display shows, and a target's jump button selects its prim in the tree. |
| `interface_registration.py` | Registration of the UI's scene property, classes, tool, and subscriptions; the load handler, which subscribes again; and the load, undo, and redo handlers, which recompute selectability from the active tool. |
