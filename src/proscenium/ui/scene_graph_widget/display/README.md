# `proscenium.ui.scene_graph_widget.display`

The scene graph widget's display: the `prim_tree/` model drawn in Blender as a virtualized `UIList`, for a host to place ([Scene Graph UI](../../../../../docs/phase3/scene-graph-ui.md#the-widget)). It registers no panel that shows by itself: its one panel is the settings popover its gear opens. A host registers it, creates named views, gives each a stage, and calls `draw_tree` and `draw_details` from its own panels' `draw`; it says, for the key watcher, which regions are showing each view, and may hear each view's selection changes. A host holds only a view's name, and changes and reads it through the package's functions.

Each view's state is a `prim_tree.PrimTreeView`, and the UIList draws from an item of the window manager's `proscenium_scene_graph_views` collection named for the view: one empty row item per visible row, the active row, and the search fields. The item mirrors the view, apart from the search fields, which hold the query being edited until it's applied to the view. The window manager's properties aren't saved, so a load handler makes the items again after each load, from the views.

It draws with what the widgets share: the theme's colors, tinted and badge icons, and the copy-path operator from `widget_resources/`, which its registration registers too; columns, their header and settings from `columned_list/`; the search box from `search_box.py`; and timers from `widget_updates.py`.

Its modules import each other in the order the table lists them, each only from those above it; `tests/bpy_free/test_import_tiers.py` fails on any cycle among a unit's modules.

| File | Holds |
|---|---|
| `__init__.py` | The package's exports: the names hosts use, `register`, `unregister`, `create_view`, `remove_view`, `set_stage`, `select_prim`, `selected_path`, `draw_tree`, `draw_details`, `apply_pending`, and `ViewNotFoundError`. |
| `scene_graph_views.py` | The views by name, each a `SceneGraphView`: its `PrimTreeView`, and what its host said about where it shows and who hears its selection. It knows nothing of Blender's data, and hosts never see it. |
| `scene_graph_properties.py` | The property groups a view is drawn from, `SceneGraphViewProperties` (one view's rows, active row, search fields, and settings: which columns show, and their widths) and `SceneGraphRow` (a row item with only a computed tooltip), with their update callbacks, the window manager's collection of them, and everything that reads or writes them: making a view's item from the view, syncing its row items with its tree, reading its search fields, `apply_stage_changes`, which a view's stage timer calls to read stage changes once an edit is over, and `apply_pending`, which its search timer calls to run a search a pause after the fields last change, reading any stage changes too. |
| `scene_graph_operators.py` | The rows' buttons: `SceneGraphToggleRow`, the disclosure triangle, with its tooltip from its `description`, and `SceneGraphGuideLine`, the never-enabled button a tree guide line is drawn as. Both internal, pushing no undo step. |
| `instancing_colors.py` | Instancing's color, the colors an instance's row and its proxies' mark them in, and the instance badge's look. |
| `scene_graph_keys.py` | `SceneGraphWatchKeys`, the modal operator that takes Left and Right, plain and with Shift, over a region showing a view, before its UIList does, and passes every other event on; one per window, started in every window at registration and in any window that draws a view whose running modal operators include none. |
| `list_columns/` | The list's columns, a module each: the name column, which draws the tree, and the Children, Kind, Type, and Copy Path columns after it. |
| `scene_graph_drawing.py` | `SceneGraphList`, the UIList, which draws each row's name cell and then the cells of the shown columns after it, in the order `list_columns.COLUMNS` lists them; `SceneGraphSettings`, the popover a gear at the status line's end opens for a view's settings; `draw_tree`, with the status and header row above the list and the search box below it, which also starts a key watcher in its window if it has none; and `draw_details`. |
| `scene_graph_hosting.py` | What a host calls: `create_view`, `remove_view`, `set_stage`, `select_prim`, and `selected_path`. |
| `scene_graph_registration.py` | `register` and `unregister`: the shared display, the classes, the window manager's collection, the key watchers, and the load handler that makes each view's properties again and untracks the watchers the load ended. |
